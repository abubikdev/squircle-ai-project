# squircle-ai-project

## Project Checklist

This checklist summarizes the required outputs for each week of the project.

- [x] **Week 1 – Planning & Git**
  - [x] Choose the project topic
  - [x] Create a Gantt chart
  - [x] Project manager sets up the Git repository and invites team members
  - [x] Create a wireframe on paper or in Figma

- [x] **Week 2 – Semantics & Structure**
  - [x] Create all HTML pages
  - [x] Define the basic structure (header, footer, navigation)
  - [x] Make the first Git push

- [x] **Week 3 – Bootstrap & Design**
  - [x] Implement Bootstrap components (grid, navigation, modals, cards)
  - [x] Refine custom CSS styling
  - [x] Use Google Fonts for typography

- [x] **Week 4 – Validation & Presentation**
  - [x] Test and validate layout in DevTools (mobile version)
  - [x] Fix any issues found
  - [x] Document ORBIS and prepare the presentation
